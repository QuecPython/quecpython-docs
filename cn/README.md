# QuecPython 中文文档

> QuecPython 是移远通信基于 MicroPython 为蜂窝物联网模组移植的Python开发环境，使用Python脚本快速开发物联网终端应用。

## 📖 文档说明
本文档是 **QuecPython 中文文档**，包含快速入门、API参考、应用开发指南、开发板使用指南、FAQ、示例教程等内容。

## ✨ QuecPython 优势
1. Python3语法，无需C语言基础，脚本动态加载，不用编译固件即可调试
2. 适配移远 Cat.1 / Cat.4 / NB‑IoT / Cat‑M 系列模组
3. 内置网络、短信、定位、外设(GPIO/UART/I2C/SPI)等丰富接口库
4. 配套工具：QPYcom调试工具、VSCode QuecPython插件
