# 固件升级

众所周知，做 QuecPython 脚本软件开发离不开 Python 脚本运行环境，而这个运行环境则是编译在支持 QuecPython 的模组的固件中的。因此，开发拿到移远通信的模组时，必须先烧录 QuecPython 团队提供的、支持了Python 脚本运行环境的固件，方能进行脚本软件开发。

开发需要升级固件时（比如特性更新、bug修复），可以使用烧录工具重新烧录新版固件，或者使用 OTA 方式在线升级固件。

对于已经做了外壳封装（未留出烧录端口）、或者已经出售的产品，无法通过烧录工具升级的，只能使用 OTA 的方式升级固件。

本文将重点介绍固件烧录和 OTA 升级两种方式的原理和使用教程。
