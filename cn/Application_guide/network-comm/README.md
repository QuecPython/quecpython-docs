# 网络与通信

本系列文档主要是网络与通信相关的内容，包含网络通信的重要硬件组件（如 SIM 卡、各类网卡等）、网络通信协议（网络链路、TCP/IP、网络应用协议等）、电话及短信等。

具体来说：

- SIM 卡部分包括 SIM 与 eSIM。

- 网卡部分包括蜂窝网络、以太网卡、Wi-Fi 网卡、USB 网卡。

- 网络通信协议包括 TCP/IP、HTTP、MQTT、FTP等。
