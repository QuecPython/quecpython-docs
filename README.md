# quecpython‑docs

> QuecPython 文档仓库，提供中英文版本文档源文件，作为 QuecPython 开发者查阅、贡献文档的源码仓库。

[中文](./README.md) | [English](./README.en.md)

## 📖 简介

QuecPython 是移远通信基于 MicroPython 移植、面向蜂窝物联网模组的 Python 二次开发平台，兼容 Python3 语法，支持动态脚本加载，降低物联网嵌入式开发门槛。
本仓库存放 QuecPython 全套文档源码，分为中文、英文两套文档源，支持本地构建、在线预览，欢迎社区参与文档修订与补充。

## 📂 仓库目录结构

```Plain Text
quecpython‑docs
├── cn/                # 中文文档入口
├── en/                # 英文文档入口
├── LICENSE            # MIT许可证
├── README.md
└── README.en.md
```

## 📝 文档使用说明

1. 中文文档源文件位于 `cn/` 文件夹；英文文档源文件位于 `en/`。

2. 文档全部使用 Markdown 格式编写。

3. 每个子目录的 `README.md` 为该章节首页入口文件。


## 👨‍💻 参与贡献

欢迎提交 Issue 和 Pull Request 完善文档，贡献步骤：

1. Fork 本仓库

2. 新建分支，分支命名建议：`feat/xxx` / `fix/xxx`

3. 修改对应文档源文件，本地预览确认渲染正常

4. 提交 commit，推送至你的 Fork 仓库

5. 提交 Pull Request，等待审核合并

> 提交 PR 前，请检查：Markdown 链接、图片路径、中英文术语一致性。
>
