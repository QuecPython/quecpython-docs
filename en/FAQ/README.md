# QuecPython-FAQ

## Document Description

QuecPython-FAQ is a summary document of frequently asked questions released by QuecPython team. This repository aims to help our users to quickly locate those questions and get answers through simple explanations. The current categories of FAQ cover: development environment, application solutions, software framework, hardware related and test verification.

Before using QuecPython-FAQ, we strongly recommend that you learn how to use this website through the [Instruction](./guide/README.md).
