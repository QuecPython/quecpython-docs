# FAQ on Application Framework

### **What is EventMesh?**
EventMesh is a kind of dynamic basic middleware. In the context of event-driven architecture, events refer to changes, operations or observations in the system. They will generate notifications and then respond to each processor function that responds to the event.

### **How to debug some of released component and framework codes in module?**


Some of the open-source components and framework codes provided externally can be viewed and downloaded on [Github](https://github.com/QuecPython/modules). After the download is completed, you can upload it to the module and execute.
