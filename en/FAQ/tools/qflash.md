# FAQ on QFlash

### **Why is there only one serial port after downloading firmware via QFlash?**&#x20;

Close QFlash, reboot the module and try again.

### **Why is it a failure to download the firmware suffixed with .bin  using QFlash?**&#x20;

The QFlash cannot directly download the firmware with the **.bin**  and needs to be modified to **.zip**.

### **Is there any limitation when detecting the download port via QFlash? **

It is indeed. As a result, please power on device before downloading.
