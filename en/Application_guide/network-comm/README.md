# Network and Communication

This series of documents primarily cover topics related to network and communication, including essential hardware components for network communication (such as SIM cards, various network interface cards, etc.), network protocols (network links, TCP/IP, network application protocols, etc.), voice call and SMS.

Specifically:

- The SIM card section covers both physical SIM cards and eSIMs.

- The network interface card section includes cellular network interface card, Ethernet  network interface card, Wi-Fi network interface card, USB network adapters.

- Network protocols include TCP/IP, HTTP, MQTT, FTP and others.
