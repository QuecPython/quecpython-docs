# Peripheral interfaces

It is available to control external circuit collect data and communicate with other external devices based on these interfaces. 

It contains but not limited to following aspects. 

- [GPIO](./GPIO.md)
- [UART](./UART.md)
- [SPI](./SPI.md)
- [IIC](./IIC.md)
- [PWM](./PWM.md)
- [ADC](./ADC.md)
