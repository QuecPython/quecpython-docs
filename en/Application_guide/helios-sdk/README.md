# About Helios SDK

The Helios SDK has the following features:

- Helios SDK is a C language-based SDK that provides the QuecPython runtime environment.
- It allows users to call system interfaces to implement most of the functions related to Quectel modules.
- It also allows users to extend functionality within the QuecPython virtual machine.
- Helios SDK provides the menuconfig feature for users to customize functionality.
