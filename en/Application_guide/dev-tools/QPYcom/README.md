# QPYcom User Guide

[QPYcom](https://developer.quectel.com/en/resource-download?cid=260) is a full-stack development and debugging tool for QuecPython. It supports basic functions such as REPL interaction, file transfer,and firmware combination and download. It also includes extended functions such as DFOTA package making and partition adjustment.

This series of documents will introduce the use of *QPYcom* from the following aspects:

- [GUI](./qpycom-gui.md)
- [Firmware&Script Download](./qpycom-dw.md)
- [REPL](./qpycom-repl.md)
- [Script Combination, Backup, Encryption](./qpycom-merge.md)
- [Extended Functions](./qpycom-ext.md)
