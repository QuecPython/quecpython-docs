# QuecPython English Documentation

> QuecPython is a Python runtime ported by Quectel based on MicroPython for cellular IoT modules. Developers can build IoT applications quickly with Python scripts.

## 📖 Document Description 
This is **official English documents for QuecPython**, including getting‑started guides, API references, development manuals, hardware docs, FAQs and sample tutorials.

## ✨ QuecPython Advantages 

1.  Python 3 syntax, no C language background required. Scripts support dynamic loading; debugging can be performed without firmware compilation. 
2.  Compatible with Quectel Cat.1 / Cat.4 / NB‑IoT / Cat‑M series modules. 
3.  Built-in rich interface libraries for network, SMS, positioning, peripherals (GPIO/UART/I2C/SPI), etc. 
4.  Supporting tools: QPYcom debugging tool, VSCode QuecPython extension.
