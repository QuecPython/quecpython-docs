## Preparation Work

**Hardware:**

- A [**QuecPython_EC2X_EVB**](../../../Dev_board_guide/en/ec2x-evb.md) (For detailed information about the EVB, see the EVB list below.)
- **USB-A to USB-C cable** 
- **PC** (Windows7 & Windows10 & Windows11)

**EVB List:**

- [EC2X_EVB](../../../Dev_board_guide/en/ec2x-evb.md)
- [BG95_EVB](../../../Dev_board_guide/en/bg95-evb.md)
- [EC200X_EVB](../../../Dev_board_guide/en/ec200x-evb.md)
- [EG91X_EVB](../../../Dev_board_guide/en/eg91x-evb.md)
- [EC600U_235_EVB](../../../Dev_board_guide/en/ec600u-235.md)
- [BG95/EG915U/EG912U_Core_EVB](../../../Dev_board_guide/en/bg-eg-core-evb.md)


**Software:**

- Download and install the **USB driver** for developing and debugging QuecPython modules.
- Download the **debugging tool** — QPYcom (QuecPython full-stack development debugging tool).
- Get the **QuecPython** firmware and related software resources.
- Install a **text editor** for the **Python language**, such as [VSCode](https://code.visualstudio.com/).

**Device start:**

Power on and start the device according to the equipment to be used and refer to the development board list above (including antenna installation, SIM card installation, power connection, power on, etc.)
