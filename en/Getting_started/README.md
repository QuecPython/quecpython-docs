# Getting Started with QuecPython

## Document Description

*Getting Started with QuecPython* is intended for developers who are new to QuecPython. As the opening guide of the full documentation set, it helps developers get a quick overview of QuecPython and walks them through the complete workflow from environment preparation to running their first script. Even beginners with zero prior experience can follow this document to get started.
